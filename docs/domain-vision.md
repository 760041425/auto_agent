# 领域愿景

系统的核心问题不是“运行一个视觉模型”，而是将不同来源、不同坐标表达和不同生命周期的数据，可靠地转化为可追踪的定位结果。

## 核心能力

- **地图准备**：把原始 LAS、轨迹和相机信息转成可检索、可回投影的地图资产。
- **影像任务**：接收查询影像，管理比较或定位任务的生命周期。
- **空间定位**：从影像特征与地图资产建立 2D–3D 对应，估计区域坐标或相机位姿。
- **结果解释**：保存置信度、内点、匹配点、验证信息和可视化，使结果能够复核。

## 设计原则

- 坐标系、偏移、相机内外参必须显式，不依赖隐含约定。
- 地图构建是离线资产生命周期；查询定位是在线任务生命周期，二者不混为一个模型。
- 算法可以替换，但输入输出契约和质量指标应稳定。
- 定位失败是正常领域结果，应保留原因和证据，而不是只抛出技术异常。
