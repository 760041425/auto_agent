# 产品说明

## 目标

将现实拍摄图像与既有 LAS 点云地图关联，让用户能够：

1. 上传和管理查询图像；
2. 从图像匹配到点云中的三维位置；
3. 查看匹配置信度、三维坐标与调试结果；
4. 在移动场景中以更低延迟估计相机位姿。

## 核心用户

- 维护或消费三维点云地图的工程人员；
- 需要把现场影像定位到点云坐标系的视觉算法人员；
- 通过 Web 界面执行预处理、匹配和定位验证的测试人员。

## 当前范围

- 单机 FastAPI 服务与静态 Web 界面；
- LAS/COLMAP/轨迹数据的预处理与多视角投影；
- 图像上传、比较任务、报告和视觉定位；
- SIFT、SALAD、LightGlue、RoMa、ACE 等算法路径。

## 非目标

- 当前不承诺多租户、权限、云端弹性调度或生产级分布式任务队列；
- 当前不保证所有 LAS point format 和所有外部渲染器均兼容；
- “实时”是优化方向，必须由基准测试证明，不能只依据算法论文中的理论延迟。
