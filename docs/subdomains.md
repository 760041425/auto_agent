# 子域划分

| 子域 | 类型 | 说明 | 投入原则 |
| --- | --- | --- | --- |
| 空间定位 | 核心子域 | 2D–3D 对应、候选检索、PnP、位姿比较与优化直接决定产品价值 | 优先建模、测试和性能验证 |
| 地图准备 | 支撑子域 | 将 LAS 与轨迹数据加工为定位可消费的地图资产 | 稳定契约，隔离外部工具 |
| 任务与影像 | 支撑子域 | 上传、任务状态、恢复、报告持久化 | 强调生命周期一致性 |
| Web 展示 | 通用子域 | 文件上传、任务触发、状态轮询和结果可视化 | 保持轻量，可替换 |
| 数据库与运行脚本 | 通用子域 | SQLite、进程管理、日志和部署 | 不承载核心定位规则 |
