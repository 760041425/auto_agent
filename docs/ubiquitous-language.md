# 统一语言

| 术语 | 定义 | 避免使用 |
| --- | --- | --- |
| LAS 地图 | 作为空间真值来源的 LAS 点云及其元数据集合 | “点云文件”代替整个地图资产 |
| 查询影像 | 用户上传、等待比较或定位的现实图像 | `image` 在没有上下文时泛指所有图 |
| 地图投影 | 从三维地图按指定位姿渲染出的二维参考图 | 查询影像 |
| 四向斜地面视图 | 生产地图投影的 Euler 姿态集合：yaw 0/90/180/270、pitch -15、roll 0；相机 forward 世界 Z<0，但不是垂直俯视 | 多 pitch 实验视图、水平八向视图 |
| XYZ 图 | 地图投影中每个有效像素对应的绝对三维坐标数组 | 深度图 |
| 法线图 | 地图表面方向在投影视图中的三通道表达 | RGB 图 |
| 地图瓦片（Tile） | 一张地图投影及其 XYZ、法线、实际渲染位姿（位置/Euler/四元数/COLMAP 行）、相机参数和特征元数据的组合 | 只把 PNG 称为 tile |
| 预处理 | LAS 下采样、八叉树构建、投影、特征索引或 ACE 训练的离线流程 | 定位 |
| 比较任务 | 查询影像与地图瓦片匹配并生成区域三维坐标的任务 | 定位任务 |
| 定位任务 | 估计查询相机位姿的任务 | 比较任务 |
| 位姿 | 相机相对于地图坐标系的旋转与平移 | 单个三维点 |
| 匹配点 | 查询影像二维点与地图三维点形成的对应关系 | 只含二维-二维对应的原始特征匹配 |
| 内点 | 通过几何模型验证的匹配点 | 所有匹配点 |
| PnP 综合评分 | `score = inlier_count / (reproj_error_px + 1e,6)`，多阶段焦距搜索后取最优 | 仅内点数 |
| 质量门控 | PnP 结果的多维度门控（score / inliers / reproj_error），输出 `quality_passed` 与 `quality_reasons` | 绝对精度、独立真值 |
| 几何拟合诊断 | 同一观测数据上计算的内点数、比例和像素残差，用于发现拟合问题 | Benchmark、绝对精度 |
| 本地坐标交叉验证 | 定位任务保存 query→SLAM XY 单应矩阵和最终位姿 XYZ NPY；前端取归一化点后同时返回 H→SLAM XYZ 与 NPY XYZ 并报告差值 | 外部服务联调、独立位姿真值、绝对定位精度 |
| 坐标差最终判定 | 对最终 NPY 多个有效像素计算 H→SLAM XYZ 与 NPY XYZ 三维差，以中位差和配置门槛决定 V2 与 SALAD+RoMa 原版结果是否可信 | 内点门槛、相似度排序、单点差、独立真值精度 |
| 无法判定 | 结果未生成坐标差判据产物（无 H→SLAM/NPY 多点差）时展示的独立状态：既不可信也不伪造数值，附明确 reason；徽章与「坐标差最终判定」卡片在此状态下均不显示 ✓ | Java 旧 `reliable`（LAS 验证率、内点数等辅助判据）单独产生可信徽章 |
| 多阶段焦距搜索 | PnP 前在归一化焦距空间做粗→细搜索，找到最优相机内参估计（参考 slam-map） | 固定内参、单次 PnP |
| 独立真值 Benchmark | 在与地图和算法输入解耦的 holdout 位姿真值上计算平移/旋转误差的可复现评估 | 同源 NPY 自比较、单图拟合诊断 |
| 报告 | 比较任务的持久化结果及其置信度、坐标和验证证据 | 运行日志 |
| 规格包 | `specs/<id>/` 下描述一次变更的完整资产集合 | 单独一份需求 Markdown |

坐标字段统一写作 `x/y/z`；像素坐标写作 `px/py`；旋转向量和平移向量写作 `rvec/tvec`。出现局部坐标、偏移坐标或经纬高时，必须在接口或规格中明确转换方式。
