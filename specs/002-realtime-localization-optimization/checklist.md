# 002 检查清单

## Definition of Ready

- [x] 算法路径、上下游资产和结果边界明确；
- [x] 功能验收标准具有稳定 AC-ID；
- [x] 未验证性能数字已从承诺中移除；
- [x] 风险和回滚路径已记录；
- [ ] 目标硬件、数据集和实时阈值已批准。

## Definition of Done

- [x] 八件套规格文件完整；
- [ ] AC-002-01 至 AC-002-07 均有自动化证据；
- [ ] MapTile 版本和一致性有契约测试；
- [ ] 多算法结果可独立成功/失败，不相互覆盖；
- [ ] 冷/热启动 p50/p95 报告可复现；
- [ ] 默认算法与降级策略已决策；
- [ ] 快速测试和漂移检查通过。

当前只能宣告“优化路径存在且规格已整理”，不能宣告“实时目标已达成”。
