# 001 实施计划

## 上下文分配

| 上下文 | 职责 | 当前代码 |
| --- | --- | --- |
| 任务与影像 | 影像与任务生命周期、报告持久化 | `api/models.py`、`api/routes/images.py`、`api/routes/tasks.py` |
| 地图准备 | LAS 读取、下采样、八叉树、投影和坐标图 | `services/las_processor/`、`api/routes/preprocess.py` |
| 空间定位 | 特征匹配、几何验证和三维对应 | `services/matcher/`、`services/localizer/` |

## 依赖方向

1. FastAPI 路由把 HTTP 输入转换为应用请求；
2. 应用编排维护事务、任务状态和调用顺序；
3. 领域结果表达成功、失败、坐标和质量；
4. SQLAlchemy、文件系统、OpenCV/模型与外部二进制作为适配器接入。

存量路由仍直接调用具体服务。本特性先用测试固定契约，再在独立任务中抽取应用用例，避免一次性目录迁移。

## 数据与契约

- `Image`：ID、原始文件名、存储路径、状态、创建时间；
- `Task`：ID、影像 ID、类型、状态、请求、结果、错误、完成时间；
- `Report`：任务 ID、是否匹配、数量、中心坐标、区域、置信度和验证证据；
- `MapTile`：投影图、XYZ/法线图、位姿、特征和坐标参考。

## 验证顺序

1. 用纯内存/临时目录测试影像与资源校验；
2. 用 SQLite 临时库测试任务状态和报告一一对应；
3. 用小型确定性地图夹具测试像素到三维坐标契约；
4. 最后才运行真实 LAS、模型和外部二进制的系统测试。
