# 001 决策

## DEC-001-01：显式触发预处理

- 状态：接受
- 决定：当前基线只承诺 API 显式触发，不承诺目录监视。
- 原因：与现有实现一致，也能避免未受控的大型离线任务。
- 后果：若未来需要自动发现 LAS，必须新增规格、去重规则和恢复测试。

## DEC-001-02：报告使用地图坐标语义

- 状态：接受
- 决定：没有 CRS 转换证据时，报告字段称为 `x/y/z`，不称经纬高。
- 原因：避免把局部坐标、偏移坐标误报为地理坐标。

## DEC-001-03：保留存量目录，渐进抽取上下文

- 状态：接受
- 决定：本轮不把 `api/`、`services/` 整体搬入 `contexts/`。
- 原因：目录搬迁本身不创造领域模型，并会在测试不足时放大回归风险。
- 后果：`contexts/*/README.md` 持续记录目标边界和当前映射。
