# 001 风险

| ID | 风险 | 触发信号 | 缓解 | 回滚/降级 |
| --- | --- | --- | --- | --- |
| **RISK-001-01** | 坐标系或偏移被隐式解释 | 同一点在不同接口数值不一致 | 契约携带 CRS/offset，统一使用地图 `x/y/z` | 暂停对外转换，只返回原地图坐标 |
| **RISK-001-02** | 大 LAS 或投影阻塞请求 | 请求超时、线程耗尽 | 后台任务、进度接口、资源上限 | 关闭重处理入口，保留既有地图资产 |
| **RISK-001-03** | 外部二进制/模型缺失 | 文件不存在、导入或下载失败 | 启动/任务前置检查和可诊断错误 | 使用明确标注的轻量适配器或拒绝任务 |
| **RISK-001-04** | 运行产物进入 Git | `git status` 出现地图、影像、日志 | `.gitignore` 与 drift check | 从变更中移除产物，不删除用户本地数据 |
| **RISK-001-05** | 后台线程与数据库状态漂移 | 重启后任务永久 running | 恢复策略与幂等状态迁移测试 | 将不可恢复任务标为 failed 并保留原因 |
| **RISK-001-06** | 删除影像造成孤儿记录或误删文件 | 任务/报告引用断裂 | 先决策级联规则，再实现事务和文件补偿 | 禁止级联删除，仅返回冲突 |
