# 001 澄清记录

| ID | 问题 | 结论 | 状态 |
| --- | --- | --- | --- |
| CL-001-01 | LAS 放入目录后是否自动处理？ | 当前实现通过预处理 API 显式触发；目录监视不在本期范围。 | 已澄清 |
| CL-001-02 | 报告坐标是否必然是经纬高？ | 否。对外统一称地图坐标 `x/y/z`；只有在 CRS 与转换明确时才可表达为经纬高。 | 已澄清 |
| CL-001-03 | 报告入口是什么？ | 当前为 `GET /api/tasks/{task_id}/report`，旧文档中的独立 `/api/reports/{id}` 不作为基线。 | 已澄清 |
| CL-001-04 | 比较任务与定位任务是否同一概念？ | 否。二者共享持久任务设施，但业务目标、状态结果和验收分别定义。 | 已澄清 |
| CL-001-05 | 删除影像是否级联删除任务、报告和文件？ | 当前策略需单独确认；在确认前不得把级联行为写成验收承诺。 | 开放 |
| CL-001-06 | 支持哪些 LAS point format？ | 已知 octree 工具只兼容 0–3；适配或转换责任属于地图准备边界。 | 已澄清 |

## 阻塞项

`CL-001-05` 会影响删除行为的契约测试，但不阻塞上传、比较和报告主路径的基线整理。
