# 验收测试模式

## 用例字段

| 字段 | 内容 |
| --- | --- |
| ID | `AT-<spec>-<NN>` |
| AC | 一个或多个验收标准 |
| 层级 | L1 / L2 / L3 / 非功能 |
| 前置 | 数据、身份、版本、环境 |
| 步骤 | 可重复的最小操作 |
| 预期 | 外部可观察结果 |
| 证据 | 测试、响应、查询、截图或日志 |

## 分层

### L1 单元/契约

- 领域状态迁移、计算规则、错误类型；
- 请求/响应 schema、事件和文件格式；
- 不依赖网络、真实数据库、大模型或真实大文件。

### L2 集成

- HTTP 路由到数据库/文件系统；
- 事务、幂等、恢复和并发；
- 第三方适配使用沙箱或受控替身；
- 验证真实边界，避免把所有调用 mock 掉。

### L3 用户路径

- 从页面入口走完整操作；
- 断言页面结果、状态、错误和刷新后行为；
- 检查 console 和非预期网络错误；
- 截图展示真正的验收结果，而非只截空页面。

## 横向场景

| 类型 | 示例 |
| --- | --- |
| 成功 | 最小合法输入、典型输入 |
| 输入 | 空值、边界、超长、损坏、未知 ID |
| 权限 | 未认证、越权、只读角色 |
| 并发 | 重复提交、并发更新、锁冲突 |
| 恢复 | 进程重启、任务重试、部分失败 |
| 兼容 | 老数据、老客户端、版本化契约 |
| 可观测 | 错误码、日志、状态与诊断证据 |

## 判定规则

- 测试代码存在但未执行：`not run`。
- 只在 mock/本地验证：不能替代要求的真实环境。
- 偶发失败：先归类为不稳定，不能直接 pass。
- 规格没有明确期望：`blocked` 或 `不可判定`。
